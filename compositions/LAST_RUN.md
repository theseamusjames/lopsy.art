# Last run: Yogurt Zeppelin (claymorphism poster, 1200x1600)

Project type: poster; soft claymorphism dairy-delivery blimp over a pastel sky.

Tools/features used:
- Linear + radial Gradient (Advanced stops), Elliptical Marquee fills, Lasso fills (fins, cup, stars)
- Layer effects as the clay recipe: Drop Shadow, Inner Glow, Outer Glow, Stroke (headline), Color Overlay (tagline)
- Multiply shade layers clipped by the live selection; Select Feather (soft highlight), Select Inverse + Delete (stripe)
- Groups: Group Layers, group move, group rotate with Move handles + undo/redo exact; rotated Badge Group
- Text: Fredoka Bold/SemiBold, size/weight edits, Align center horizontally, arrow-key nudging
- Dodge/Burn (undone, then repaired), click-to-place ruler guides + marquee snap to guide, Add Noise (Mono) on Overlay layer, 50-step undo/redo round trip

Palette: pastel peach -> pink -> lavender sky, mint hull, hot-pink + purple type, cream/yellow accents, white clay clouds.
