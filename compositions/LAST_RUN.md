# Last Run — Neon Samurai (Pixel-Art Digital Painting)

**Topic:** Neon Samurai (random letters "n" + "s")
**Art Style:** pixel-art
**Project Type:** digitalPainting
**Document:** 600 × 800

## Tools Used
- **Gradient** — linear background (dark purple→deep blue)
- **Shape** — ellipse (helmet dome, shoulder armor), polygon (4-sided diamond crest)
- **Brush** — hard brush for face silhouette, katana blade
- **Spray** — neon particle accents (cyan, pink)
- **Text** — Impact font, "NEON SAMURAI" title
- **Eraser** — cleanup test layer
- **Rectangular Marquee** — selection for copy/paste/blend
- **Move** — arrow key nudge of pasted layer

## Layer Effects
- Outer Glow (crest, face/eyes, katana blade, text title)
- Stroke (shoulder armor)

## Blend Modes
- Screen (pasted layer, duplicate blade)

## Groups
- Group with particles layer moved in, opacity 85%

## Other
- Grid toggled on (View > Show Grid)
- Undo ×3, Redo ×3, then final undo/redo pair
- Layer opacity adjustments (grid 25%, particles 60%, paste 50%, group 85%, blade copy 40%)
- Duplicate layer with blend mode
